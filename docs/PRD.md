# Fumble 失手录 · PRD

## 一、产品定位

**一句话**：把日常的小翻车，变成一张张可以收藏的复古彩票。

**类型**：情绪记录 / 轻游戏化收藏 App（个人作品集向，但按商业落地标准设计）

**核心价值**：
- 用"开奖式"仪式感，把"糟糕的一天"翻译成"今天又集齐一张"
- 从负向情绪 → 中性收藏行为的转译，降低自我攻击
- 收集驱动的长期留存

---

## 二、用户与场景

**目标用户**：18–32 岁、爱记录、爱手账/集邮文化、对复古视觉敏感的年轻人

**典型场景**：
- 通勤路上洒了咖啡 → 打开 App "我又失手了" → 30 秒发一张票
- 晚上情绪崩了 → 写下来 → 烧信仪式 → 入册
- 周末翻彩票册回看，"原来我这周抽到了 3 张传奇"

---

## 三、核心信息架构

```
首页 Home          ← 当日主入口 + 大按钮"我又失手了"
  ↓
记录 Record        ← 选类别 → 描述 + 心情指数
  ↓
揭晓 Reveal        ← 仪式交互 → 揭幕 → 盖戳 → 入册
  ↓
彩票册 Book        ← 收藏列表（筛选/稀有度）
  ↓
详情 Detail        ← 单张大图 / 分享 / 撤销
```

底部导航 3 Tab：今日 / 彩票册 / 我

## 四、12 类 × 12 仪式

**日常层（6）**：洒了 / 摔了 / 忘了 / 丢了 / 说错话 / 其他·日常
**情绪层（6）**：社死 / 被拒 / 拖延 / emo / 破防 / 其他·情绪

| 类别 | 仪式 | 交互 |
|---|---|---|
| 洒了 | Wipe | 手指擦掉屏幕水渍 |
| 摔了 | Puzzle | 拖动 4 块碎片归位 |
| 忘了 | Fog | 拨开迷雾 |
| 丢了 | Rummage | 点击拨开杂物 |
| 说错话 | Blow | 左右划散粉色尴尬云 |
| 其他·日常 | Smash | 长按砸开盲盒 |
| 社死 | Wax | 长按破开火漆封条 |
| 被拒 | Plane | 上滑折成纸飞机扔出 |
| 拖延 | Calendar | 下拖撕掉过期日历 |
| emo | Umbrella | 移动伞接住下落票券 |
| 破防 | Kintsugi | 沿裂痕描金缝合 |
| 其他·情绪 | Burn | 写下心里话点燃 |

**铁律**：所有仪式 6–15 秒；不做"等雨停"这种反交互的静态等待。

## 五、稀有度系统

| Tier | 权重 | 视觉差异（追加式） |
|---|---|---|
| Common 寻常券 | 60% | 标准米色票 + 黑邮戳 |
| Rare 稀缺券 | 25% | + 装饰性边框 |
| Epic 珍奇券 | 12% | + 渐变底色 + 紫金戳 + confetti |
| Legendary 传奇券 | 3% | + 烫金渐变 + 角花 + 旋转金环 + 双重 confetti |

**关键决策**：稀有度做**追加式**而非**平行式**——所有票仍是"同一种产品"，避免做成 4 个不同 App。

---

## 六、揭晓时刻 5 阶段状态机

`intro → ritual → revealing → stamping → revealed`

- **intro**：NOW ISSUING 邮戳从 -30° 砸入，定格 -6°
- **ritual**：12 选 1 仪式
- **revealing**：白色票面褪去
- **stamping**：稀有度大圆戳从 scale 4 砸下，定格 -14°
- **revealed**：传奇加金色光晕 + 16s 旋转金环 + confetti

聚光灯背景按 tier 动态加深（0.25 / 0.45 / 0.7）。

---

## 七、视觉与动效原则

**视觉策略**：A 70% / B 30%
- A 派（页面外壳）：极简、留白、字体层次
- B 派（票券本体）：复古、烫金、邮戳、锯齿票根

**动效优先级**：
1. 页面转场（方向感滑动：record 抽屉、detail 右推、tab 横切）
2. 按压反馈（PressButton "盖戳"重量感）
3. 揭晓戏剧化

**主动放弃**：陀螺仪 / 3D 倾斜 / 复杂 parallax（低端机性能成本太高）
